B-Trees

A self-balancing tree data structure that maintains sorted data and allows searches, sequential access, insertions, and deletions in logarithmic time.

touch_app Tap to Reveal
Answer Detail

Nodes can have more than two children (multi-way tree).

Keeps data sorted and optimized for systems that read and write large blocks of data.

Commonly used in databases and file systems like NTFS and HFS+.

Related Concept

Min-Max Heap: A specialized binary tree for double-ended priority queues.
