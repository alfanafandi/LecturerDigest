Explain why searching in a Hash Table is typically O(1).

auto_stories

The secret lies in the **Hash Function**. Instead of searching through every element (like a linear search), we compute the index directly:

index = hashFunction(key) % arraySize;

This direct access is why it's constant time. Of course, this assumes we have a good hash function with minimal collisions!
